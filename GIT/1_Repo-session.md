## Creating a Directory in Your Repository
* Create a new directory called `0x03-git` in your `alx-zero_day` repository.<br />
  Make sure to include a not empty README.md file at the root of your directory `alx-zero_day`, and in the directory `0x03.git`.<br />
  Make sure you commit and push your code to Github.<br />
  ```
  /$ cd ~/alx-zero_day
  /alx-zero_day$ mkdir -p 0x03-git  # create new directory
  /alx-zero_day$ echo "# 0x03-GIT" > /0x03-git/README.md  # include a non-empty README to 0x03.git directory
  /alx-zero_day$ git add .  # add modified/new files to index
  /alx-zero_day$ git commit -m "Updated README"
  /alx-zero_day$ git push  # push changes to GitHub
  ```
